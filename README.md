# Sathya Vamshi Mittakori | Portfolio

Personal portfolio of a Data Engineer (ETL / ELT, data warehousing, Azure & Databricks).
Live: https://vamshi-dev99.github.io/Sathya-Portfolio/

Built with React, TypeScript, Vite, Tailwind CSS and Framer Motion. All content lives in
`src/data/portfolio.ts`. Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.

```
npm install
npm run dev     # local preview
npm run build   # production build in dist/
```
